# Data (official dataset — full notes, `draft`)

Schema: `data/<subject>/unit-<n>/<slug>.md` with frontmatter
(subject/unit/topic/syllabus_ref/status) + FULL notes:

- Overview (what + why, simple words)
- Explanation (every syllabus point for the topic, in order, fully)
- Worked examples (code / tables / step-by-steps where relevant)
- Key terms & formulas
- Common mistakes
- Exam prep (likely 2-mark + long-answer questions)

Length follows importance — major topics long, minor topics complete but shorter.
No word cap. `status: draft` until peer review passes.
